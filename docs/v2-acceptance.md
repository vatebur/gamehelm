# GameHelm 2.0 验收记录

2026-11-04 在 Linux 环境完成部署及 ego-browser UI 验收。本文记录功能和验证结果。

部署使用普通用户的 `gamehelm.service`，服务状态为 `active/running`，检查时 `NRestarts=0`。部署二进制与验收构建的 SHA-256 一致。管理员保管原二进制、配置和 unit 的回滚备份。认证口令以 Argon2id 哈希保存，配置文件权限为 `0600`。

`public_origin` 和 `trusted_proxies` 为可选字段，示例默认注释。部署支持通过 HTTP 和 IP 直接访问。密码回写保留注释、其他字段与原有排版。

ego-browser 使用同一个验收工作空间，验证口令登录、服务卡片及退出登录。实际启停操作在独立验收实例中使用一次性 Docker 容器和 systemd 用户服务执行，验收实例以普通用户运行。

| UI 场景 | 结果 |
| --- | --- |
| HTTP + IP 登录 | 原口令可用，错误口令显示失败提示 |
| Docker 启动 | 状态进入运行中，显示倒计时 |
| Docker 续时 | 原截止时间增加五分钟，累计续时次数显示为 1 |
| 浏览器刷新 | 当前倒计时和续时记录保持 |
| systemd 启动 | 状态进入运行中，显示无限运行，隐藏续时按钮 |
| 缺失目标 | 统一显示异常，操作按钮禁用 |
| 取消关闭 | 服务保持运行，续时记录保持 |
| 重启 GameHelm 验收实例 | 旧会话失效，运行中的容器重新获得完整时长，续时归零 |
| 确认关闭 | Docker 与 systemd 测试目标均进入已停止，清理本轮倒计时 |
| 手机视口 | 390×844 视口，页面宽度 390，无横向溢出，完成确认关闭操作 |
| 退出登录 | 返回登录页 |

自动到期、运行时暂时失联与实例替换由自动化回归测试验证。UI 验收完成后已停止并删除临时容器、临时 systemd unit、独立验收实例及临时口令文件，ego 工作空间已关闭。
